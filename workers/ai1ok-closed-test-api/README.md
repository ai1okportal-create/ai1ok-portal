# АІ 1 ОК — закритий тестовий модуль

Це серверна частина для закритого тесту порталу. Вона зберігає лише:

- публічну назву кабінету, напрям і короткий опис;
- технічний ідентифікатор власника, отриманий із доступу Cloudflare Access;
- стан перевірки кабінету;
- запити на зв'язок та відповідь на них.

Не зберігаються телефони, документи, платіжні дані, вкладення, паролі або самі повідомлення чату.

## Захист

Модуль має працювати тільки на маршруті `access.ai1ok.com.ua/api/*`, який уже захищено Cloudflare Access. Він відхиляє будь-який запит, що прийшов не на цей домен або без підтвердженого Access email.

Для адміністратора потрібна змінна-секрет `ADMIN_EMAIL` зі значенням робочої адреси адміністратора. Її не записують у код чи Git.

## Порядок запуску

1. Створити D1 базу `ai1ok-closed-test`.
2. Створити Worker `ai1ok-closed-test-api`.
3. Додати до Worker прив'язку D1 з назвою `DB`.
4. Додати секрет `ADMIN_EMAIL`.
5. Додати маршрут `access.ai1ok.com.ua/api/*`.
6. Застосувати `schema.sql` до D1.
7. Опублікувати код із `src/index.js`.

Після цього сторінки закритого тесту можна перевести з локального збереження на `/api/...`.
